How to use

Put the Minecraft gameplay on the bottom video layer. Add this browser source on top; the lower part is transparent.

The face itself doesn't play Minecraft. The game needs a separate visible client or renderer.

Enter admin token to send test events.

Secure controls

The face does not speak. Small gifts create a quick reaction; Cowboy Hat and other configured big gifts cause a head scratch.

Character identity

Optional: realistic avatar frames

Provide three matching, publicly HTTPS-hosted PNG/WebP frames. For a believable photo-based head scratch, the scratch image must show the raised hand.

If a frame is missing, the idle image is reused. The supplied illustrated avatar already has a working scratch animation.

Keep the admin token secret. Only the control endpoint requires it; the public overlay URL is safe to use as a browser source.
